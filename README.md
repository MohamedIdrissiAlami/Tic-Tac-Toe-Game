# 🎯 Tic-Tac-Toe Game

A polished Tic-Tac-Toe game built with C# WinForms featuring custom graphics and smooth gameplay.

## ✨ Features

- **Turn-based gameplay** (Player 1: X, Player 2: O)
- **Automatic win detection** with visual highlighting
- **Game status tracking** (turns, winner, draws)
- **One-click reset** functionality
- **Custom UI** with hover effects and images

## 🚀 How to Play

1. Players take turns clicking cells
2. First to get 3 in a row wins
3. Click "Reset Game" to play again

## 🛠️ Built With

- **C# & .NET Framework**
- **Windows Forms**
- **Visual Studio**
